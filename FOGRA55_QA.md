# FOGRA55 real reference compatibility audit

Operator-supplied archive (not redistributed). ICC filename Ref-ECG-CMYKOGV_FOGRA55_TAC300.icc, SHA256 dfea0cc4f4d1fa51b80bee490751c7b559ed7c21adf15de230d6705c56c76042. ICC 2.4 prtr 7CLR Lab, order C/M/Y/K/O/G/V from clrt. A2B grids 5/5/4, B2A grids 33/33/17, all mft2. Embedded targ is ISO28178 with PC7_1..PC7_7 and no SAMPLE_ID; separate FOGRA55.txt has SAMPLE_ID, same count 4884, D50/2°/M1. Reference data, not an independent physical printer test.

Native Linux LittleCMS 2.16 opened all six pipelines (7→3 and 3→7) and created forward and reverse transforms for all four intents. The file name TAC300 is not a strict mathematical bound for every original intent: sampled reference-target relative reverse peak 365.45%, native detectTAC 376.40%; relative raw CLUT nodes mapped through output curves peak 383.43%. Nonaffine output curves mean node maximum is not a global certificate. This discrepancy should be shown rather than treating the filename as a verified limit.

A separate C implementation mirroring the beta.32 constrained search and mft2 serialization used 9³ PCS grid and explicit TAC 300% with K=0 or K≤10%. Both outputs reopened via native LittleCMS; maximum quantized K respectively 0% and 9.999237%; node TAC 300% each. On all 4884 reference Lab targets, relative-intent sampled K/TAC respectively 0%/299.19585% and 9.98398%/299.95270%; mean/P95/max DE00 of predicted output vs original separation respectively 3.897/7.848/15.209 and 3.570/7.612/11.494. Four native intents passed sampled limits. This is a mirrored diagnostic, NOT the compiled Rust app, formal equivalence or production print approval. Coarse grid and restricted inks change color; evaluate finer grids and independent actual print measurements before production. Actual Rust corpus harness and Windows UI testing still pending.

Import fix: accept ISO28178 PC<n>_<index> only when ordered explicit PROCESSCOLOR_ID or LGOMCCHANNEL ink names match the loaded ICC. Preserve provided sample IDs, generate row-based IDs only for the supported ISO format without SAMPLE_ID. Recognize declared illumination/observer/filter; reject conflicting aliases. Regression fixtures are synthetic and do not redistribute the operator's files.

Existing limitations: ICC v2 bounded correction/smoothing is unavailable; reorder remains blocked by private/characterization tags (Info, evts, targ and kTRC), and version conversion requires supported tag handling/consent. Embedded v2 swatches use predicted appearance rather than assuming the clrt coordinate encoding. No N-color fitting is claimed.
